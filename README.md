# 🌎 JC Imports

![Logo JC](img/JC%20importaciones.jpeg)

**JC Imports** é uma empresa especializada em **importação e exportação de produtos entre Brasil e Chile**, oferecendo soluções completas com foco em **segurança, agilidade e confiança**.

---

## 🚀 Sobre o Projeto
Este site foi criado para apresentar a empresa JC Imports de forma moderna, profissional e acessível em qualquer dispositivo.  
Desenvolvido com **HTML5**, **CSS3**, **Bootstrap 5** e **JavaScript**, e hospedado gratuitamente no **GitHub Pages**.

🌐 **Acesse o site online:** [https://Gui01-10.github.io/JCimportaciones/](https://Gui01-10.github.io/JCimportaciones/)
